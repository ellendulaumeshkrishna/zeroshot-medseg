What you will see

  1. Target map. For every pixel, how likely it is to be the described target, from BMC-CLIP and CorrCLIP.
  2. Five point prompts. The five highest, well-separated peaks of that map.
  3. Fifteen candidates. MedSAM2 draws three outlines per point, each with its own predicted IoU.
  4. Result. The outline MedSAM2 is most confident about.

How it works

The method has two parts. The first part finds where the target is; the second draws its exact outline.

  1. The class phrases (for example “benign tumor”, “malignant tumor”) are embedded by BMC-CLIP’s text encoder, averaged over 12 medical sentence templates.
  2. MedSAM2 splits the image into regions; DINO tells which patches look alike. CorrCLIP lets each patch average only the similar patches of its own region, which gives clean BMC-CLIP patch features.
  3. Comparing every patch with the class embeddings gives the target map.
  4. The map is blurry, so only its five highest, well-separated peaks are used, as point prompts.
  5. MedSAM2 returns three masks per point; the one with the highest predicted IoU is the output.
